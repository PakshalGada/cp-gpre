Matrix multiplication The product AB of matrices A and B is deﬁned if A is of size a × n and B is of size n × b, i.e., the width of A equals the height of B. The result is a matrix of size a× b whose elements are calculated using the formula AB[i, j] = nX k=1 A[i,k]·B[k, j].
