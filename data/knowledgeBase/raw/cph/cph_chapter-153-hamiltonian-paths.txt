Existence No efﬁcient method is known for testing if a graph contains a Hamiltonian path, and the problem is NP-hard. Still, in some special cases, we can be certain that a graph contains a Hamiltonian path. A simple observation is that if the graph is complete, i.e., there is an edge between all pairs of nodes, it also contains a Hamiltonian path. Also stronger results have been achieved: • Dirac’s theorem: If the degree of each node is at least n/2, the graph contains a Hamiltonian path. • Ore’s theorem: If the sum of degrees of each non-adjacent pair of nodes is at least n, the graph contains a Hamiltonian path.
