Applications Using the graph traversal algorithms, we can check many properties of graphs. Usually, both depth-ﬁrst search and breadth-ﬁrst search may be used, but in practice, depth-ﬁrst search is a better choice, because it is easier to implement. In the following applications we will assume that the graph is undirected. Connectivity check A graph is connected if there is a path between any two nodes of the graph. Thus, we can check if a graph is connected by starting at an arbitrary node and ﬁnding out if we can reach all other nodes.
