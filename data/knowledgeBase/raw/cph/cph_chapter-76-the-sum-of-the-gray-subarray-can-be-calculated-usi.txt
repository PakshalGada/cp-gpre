Minimum queries Minimum queries are more difﬁcult to process than sum queries. Still, there is a quite simple O(nlogn) time preprocessing method after which we can answer any minimum query in O(1) time1. Note that since minimum and maximum queries can be processed similarly, we can focus on minimum queries. The idea is to precalculate all values of minq(a,b) where b −a+1 (the length of the range) is a power of two. For example, for the array the following values are calculated: a b minq(a,b) a b minq(a,b) a b minq(a,b) The number of precalculated values is O(nlogn), because there are O(logn) range lengths that are powers of two. There are also more sophisticated techniques [22] where the preprocessing time is only O(n), but such algorithms are not needed in competitive programming.
