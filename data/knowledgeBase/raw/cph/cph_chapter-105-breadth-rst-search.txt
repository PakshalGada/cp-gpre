Breadth-ﬁrst search Breadth-ﬁrst search (BFS) visits the nodes in increasing order of their distance from the starting node. Thus, we can calculate the distance from the starting node to all other nodes using breadth-ﬁrst search. However, breadth-ﬁrst search is more difﬁcult to implement than depth-ﬁrst search. Breadth-ﬁrst search goes through the nodes one level after another. First the search explores the nodes whose distance from the starting node is 1, then the nodes whose distance is 2, and so on.
