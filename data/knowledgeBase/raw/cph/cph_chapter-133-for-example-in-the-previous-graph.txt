Cycle detection Consider a successor graph that only contains a path that ends in a cycle. We may ask the following questions: if we begin our walk at the starting node, what is the ﬁrst node in the cycle and how many nodes does the cycle contain? For example, in the graph we begin our walk at node 1, the ﬁrst node that belongs to the cycle is node 4, and the cycle consists of three nodes (4, 5 and 6). A simple way to detect the cycle is to walk in the graph and keep track of all nodes that have been visited. Once a node is visited for the second time, we can conclude that the node is the ﬁrst node in the cycle. This method works in O(n) time and also uses O(n) memory. However, there are better algorithms for cycle detection. The time complexity of such algorithms is still O(n), but they only use O(1) memory. This is an important improvement if n is large.
