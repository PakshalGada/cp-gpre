Implementation The operations of a binary indexed tree can be efﬁciently implemented using bit operations. The key fact needed is that we can calculate any value of p(k) using the formula p(k) = k&−k. The following function calculates the value of sumq(1,k): int sum(int k) { int s = 0; while (k >= 1) { s += tree[k]; k -= k&-k; } return s; } The following function increases the array value at position k by x (x can be positive or negative): void add(int k, int x) { while (k <= n) { tree[k] += x; k += k&-k; } } The time complexity of both the functions is O(logn), because the functions access O(logn) values in the binary indexed tree, and each move to the next position takes O(1) time.
