Whenever two consecutive elements are found that are not in correct order, the algorithm swaps them. The algorithm can be implemented as follows: for (int i = 0; i < n; i++) { for (int j = 0; j < n-1; j++) { if (array[j] > array[j+1]) { swap(array[j],array[j+1]); } } } After the ﬁrst round of the algorithm, the largest element will be in the correct position, and in general, after k rounds, the k largest elements will be in the correct positions. Thus, after n rounds, the whole array will be sorted. It turns out that the time complexity of such an algorithm is always at least O(n2), because in the worst case, O(n2) swaps are required for sorting the array.
